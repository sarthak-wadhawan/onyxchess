Engine optimization

Alpha-beta pruning is more effective if it discovers strong moves early. The engine can establish better bounds before spending time on less useful alternatives. Move ordering changes the sequence of candidates, not the legal move list or evaluation function.

Prioritize useful captures

The project uses MVV-LVA: Most Valuable Victim, Least Valuable Attacker. Captures of valuable opposing pieces are tried early. When two captures target equally valuable pieces, prefer the cheaper attacker.

The score_move function returns zero for a non-capture. For a capture, multiply the victim's ordering value by ten and add the attacker's priority. In this project a pawn has a higher attacker priority than a rook, so adding that priority correctly favors the pawn.

Candidate Ordering score
Pawn captures queen 4006
Rook captures queen 4004
Non-capture 0

These values determine search order only. They are not PeSTO scores and do not establish that any particular capture is objectively good. A capture can still be a trap.

How order_moves works

Assign the ordering score to each legal move and sort the list from highest to lowest. The root search and recursive search both use this order. Search still considers every candidate that is not eliminated by a valid alpha-beta bound.

Measure the effect

The two runs use the same board, depth, evaluation and pruning logic. Only move ordering changes. Select a depth and run the comparison.

Compare the returned score, number of nodes visited and number of cutoffs. At equal depth, ordering should preserve the best score; it may choose a different equally good move. Node counts may decrease, stay the same or even increase depending on the position. Try a different move on the board and rerun the test.

Finish the engine

The full system now represents a state, generates and validates actions, scores outcomes, searches future possibilities and prioritizes its work. Play the browser version next. The browser implementation is independent of the C++ engine, so the move choices and node counts can differ.
