Position evaluation

The move generator can tell us which actions are possible, but not which are desirable. To choose between positions, the engine needs a scoring function. In this project, evaluate uses PeSTO: material values, square-specific adjustments and a blend between the middlegame and endgame.

Why counting pieces is not enough

Imagine two positions with the same pieces. In one, a knight sits in the corner; in the other, it occupies a central square. A material-only score treats them as equal, even though the knight's usefulness may differ. We need a way to represent positional preferences.

PeSTO provides tuned values in centipawns for each piece and each phase of the game. A centipawn is one hundredth of a conventional pawn unit. These are evaluation units, not a probability of winning.

Piece Middlegame Endgame
Pawn 82 94
Knight 337 281
Bishop 365 297
Rook 477 512
Queen 1025 936
King 20000 20000

Give each square a value

Each piece has a table of 64 positional adjustments for the middlegame and another for the endgame. The function looks up an adjustment by piece type and square, then adds it to that piece's material value.

The board displays the actual table values from the supplied engine. Select a knight and compare a1 with d4. Change the phase to see how the preferred positions change. Then try the king: early-game safety and endgame activity are different priorities.

The board index starts at a1, but the tables are arranged from White's eighth rank downward. To use the same table for both colors, reverse the rank for White and leave Black's rank unchanged. The file remains the same.

Blend the two phases

Switching abruptly from a middlegame score to an endgame score creates an artificial discontinuity. Instead, calculate both scores, then blend them using the remaining major and minor pieces.

Piece Phase contribution
Pawn or king 0
Knight or bishop 1
Rook 2
Queen 4

A normal starting position has 24 phase points. Cap the total at 24 to account for extra promoted pieces. At phase 24 the middlegame weight is 100%; at phase zero the endgame weight is 100%. At phase 12, both scores contribute equally.

Suppose White's middlegame advantage is 80 and its endgame advantage is 20. Halfway between the phases, the blended advantage is 50 centipawns.

How evaluate works

  1. Scan the 64 squares, ignoring empty squares.
  2. Identify the type and color of each piece.
  3. Look up material and position values for both phases; accumulate separate totals for White and Black.
  4. Add the piece's phase contribution to the game phase.
  5. Subtract Black's totals from White's totals and blend the phase scores using their relative weights.
  6. Return the resulting score from the perspective of the current side to move. Negate the White-relative value when Black is active.

Returning a side-relative score allows Negamax to reuse the same evaluator for either player. The symmetric initial position should score zero. Checkmate is handled separately by search; the positional score is only an estimate for nonterminal positions.
