Getting started

A chess engine has four jobs: represent the current situation, find possible actions, judge their consequences and choose an action. We will build those jobs separately so that each can be understood and tested before connecting them.

The implementation is in C++, but the design works in other languages. The interactive examples are independent JavaScript demonstrations. You only need to understand variables, conditions, loops and functions to get started.

Divide the problem

Imagine putting every chess rule and decision into one function. Changing how we value a knight could accidentally break castling. Instead, give each part a clear responsibility.

File What it owns
types.h The shared representation of pieces, positions and moves
board.h / board.cpp Reading and changing a position
movegen.h / movegen.cpp Finding actions that obey the rules
eval.h / eval.cpp Assigning a numerical value to a position
search.h / search.cpp Looking ahead and selecting a move
main.cpp Managing the interaction between the player and engine
makefile Building the executable

How the modules work together

  1. The game loop asks the board for its current state.
  2. The move generator finds legal actions from that state.
  3. Search explores those actions on temporary copies of the board.
  4. Evaluation gives each position a score.
  5. The game loop applies the selected action to the real board.

The board does not need to know how search works. The evaluator does not need to know how the player entered a move. This separation is what makes later changes manageable.

Build the program

A compiler translates each implementation file into an object file; a linker combines these files into an executable. The Makefile records that process so it can be repeated consistently. Our project uses C++17, optimization and compiler warnings. If your Makefile does not track header dependencies, perform a clean rebuild after changing headers.

Begin with a small program that displays a message. Run make, then run the generated chess executable. If the message appears, the toolchain works. Add the other modules one at a time rather than debugging everything at once.
