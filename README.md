### Functionality
1. Tutorial/documentation website
2. Simple, easy to use navigation between tutorials
3. Access 13 chess engine development tutorials.
4. Navigate and search through individual tutorials.
5. Explore 21 interactive chessboard demonstrations.
6. Visualize piece movements and legal moves.
7. Interact with special-move demonstrations.
8. Visualize position evaluation using heatmaps.
9. Explore interactive Minimax and Negamax search trees.
10. Visualize alpha-beta pruning in action.
11. Compare move-ordering strategies.
12. Play chess against a computer opponent, with options to choose sides, reset, undo, and analyze the game.
13. Run entirely in the browser without a backend.

### How to Run Locally

Step 1 - Clone the repository in a new directory </br>
Step 2 - just open index.html, nothing else is required!
