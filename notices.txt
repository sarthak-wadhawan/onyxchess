# Third-party notices

The browser AI search is adapted from Zhang Zeyu's `chess-ai` minimax/alpha-beta implementation: https://github.com/zeyu2001/chess-ai (main branch, js/main.js). It uses modern chess.js calls, deterministic ordering and the supplied C++ project's PeSTO values instead of the upstream incremental Sunfish evaluator. The original upstream DOM/game code is not bundled. No claim is made that it is the same engine as the C++ code.
