Play chess

Choose your color and search difficulty in Settings. If you choose Black, the computer moves first. Select a piece and a highlighted destination. Undo reverses a full turn; Reset starts a new game with your selected color.

About this engine

The browser search adapts Zhang Zeyu's minimax and alpha-beta algorithm to current JavaScript APIs and uses the C++ project's PeSTO table values. It is not the native C++ executable. It runs entirely in the browser with no server, database or account.
